The single word my grandma would text about AI: "Robbie" — the warm pet name she gives the machine, baffled and affectionate, instead of the obvious "robot".

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt`. The word is 6 characters — inside the 30-character limit, exactly one word.
